Поэтому фраза SR02_HANDOFF «через существующую переправу» не соответствует Player.
В SR02 бесплатный мост не восстанавливается. Требуется отдельно зафиксировать отсутствие прохода
через воду и обе сухие стороны; этот маршрут не может быть объявлен успешным переходом по мосту.

считаются деревьями `WorldMapVegetationRenderer.IsTree`, а presenter привязывает их
StableEntityId к конечному запасу древесины. Перестановка таких деревьев требует
сохранения идентичности/ресурса и проверки save/load, а не простой фильтрации рендера.
Terrain/paint читаются из WorldTilePreparationCache; изменение алгоритма должно иметь
отдельный ключ кэша, иначе сравнение может фактически использовать прежние данные.
