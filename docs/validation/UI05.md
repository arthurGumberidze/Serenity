# UI05 validation — people, risk, dynasty, events and military

Date: 2026-10-31

Unity: 6000.6.4f1

Build: `Builds/UI05/Serenity.exe`

## Delivered scope

- People projects the canonical resident roster into a virtualized list and exposes home/bed/sleep, family and
  health detail without owning mutable character state.
- Dynasty projects ruler, family tree, canonical succession order, pregnancy state and succession history.
- Attention separates pending decisions from its bounded journal; choices call `EventService` and disabled/failing
  actions use typed player-facing reasons.
- Military uses virtualized unit/member lists and canonical roster, supply, training, order and combat paths. The
  workspace shows readiness and active battle/capture state; it does not invent army or combat state.
- UI05 workspaces use the approved full workspace at 1920x1080 and 1280x720@125%. Stable selection remains based
  on `StableEntityId`; no save schema, tier identity path or per-character `Update` was added.
