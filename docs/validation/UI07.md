# UI07 validation — interface acceptance, accessibility and final polish

Date: 2026-10-31. Unity: 6000.6.4f1. Scope: UI07 only.

## Delivered acceptance fixes

- The strategic IMGUI terrain now follows the real UI Toolkit `realm-map-overlay` bounds. Terrain, fog and map
  labels no longer cover the Realm header or route bar at 1280x720@125%.
- Main Menu, ruler editor, settings, confirmation modals and campaign outcome actions establish safe keyboard
  focus. Escape closes the active confirmation layer. Focus, disabled controls and scrollbars have stronger,
  non-colour-only affordances; ordinary actions and fields keep a 40 px minimum target.
- The HUD Attention control uses a bounded numeric label with the full message in its tooltip. Route cards expose
  their complete value/detail through a tooltip when the compact four-column summary clips a long place name.
- Save/load controls have stable slot names. Pause/speed controls explain their shortcuts. Victory explicitly
  permits continuing the running campaign; defeat offers load or main menu without creating alternate game state.
- Ruler/editor copy no longer exposes UMA or compatibility-test terminology. Presentation remains disposable and
  every command, save, selection, map, campaign and simulation mutation retains its existing canonical authority.
- Quitting while Realm is active no longer invokes the ordinary map-return path after world presenters have begun
  destruction; the final Player log is clean of exception/assertion/missing-reference matches.
