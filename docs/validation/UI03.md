## Attempt diagnoses

- Early compile failures exposed a missing ScreenCapture assembly reference; the smoke was kept inside the existing
  Infrastructure boundary without adding an asmdef dependency.
- The first UI03 PlayMode fixture selected an arbitrary presenter; it was changed to the canonical player-ID set.
- Initial Player smoke used a stale seed presenter after WM15 rebuilt Tier1 presentation. It now resolves the current
  presenter by StableEntityId. The smoke also waits for rendered end-of-frame pixels and rejects dark captures.
- Three P103 retries ran an old test DLL because the attached Editor had not refreshed after source edits. An explicit
  runner compile updated `Game.Tests.PlayMode.dll`; the current fixture then exposed and removed the nondeterministic
  territory-anchor path assumption, and the proof run passed.

No further user action blocks UI03. Broader visual preference review can wait for UI07 polish. UI04 is the next
unblocked task and should begin in a separate chat.
