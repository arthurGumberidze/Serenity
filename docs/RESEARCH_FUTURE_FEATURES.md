# Будущие возможности исследований — UI08-R4

Это список ограничений схемы для согласования. Будущие технологии нельзя исследовать в макете.
Текущий макет: `docs/prototypes/research-review-v4/Serenity-Research-Review.html`; R3 оставлен как история.
Ни одна действующая технология или условие эпохи не требует future-only узла.

| ID | Статус | Недостающая интеграция |
|---|---|---|
| fiber_working | PROPOSED | Нет отдельного рецепта обработки волокна или верёвки. Не закрывает доступ к существующей добыче волокон и оружию. |
| pottery | PROPOSED | Нужны рецепты керамики, ресурс-сосуд и рабочее место. Их нет в подтверждённом каталоге; технология недоступна. |
| weaving | PROPOSED | Нужны рецепт ткани, ткацкое рабочее место и тканевая одежда. Существующая кожаная одежда открывается через выделку шкур. |
| restorative_mining | PROPOSED | Флаг mine_restoration есть, но потребитель в Simulation не найден. Требуется отдельная механика; не исследуется. |
| standardization | PROPOSED | Нет подтверждённой системы качества и стандартизованных деталей. Не выдаём выдуманный бонус производства. |
| military_logistics | PROPOSED | Система снабжения существует, но отдельного эффекта capability military_logistics нет. Конкретный модификатор и потребитель требуют отдельного решения. |
| practical_anatomy | PROPOSED | Нет подтверждённого потребителя исследовательского эффекта в лечении. Снижение осложнений пока не работает и не обещается. |
| land_administration | PLANNED | U33: министры, губернаторы и ведомства. Нет работающей власти, которую можно открыть одним флагом. |
| exchange_and_measures | PROPOSED | Торговый рынок и обмен с ценами не подтверждены. Нужны отдельные правила торговли и интеграция. |
| customary_law | PLANNED | U35: законы и протесты; зависит от будущего U33, без влияния на условия эпохи. |
| trade_contacts | PROPOSED | Нет подтверждённого API торговых договоров. Не создаём фиктивные дипломатические отношения. |
| early_diplomacy | PLANNED | U36: дипломатия. Технология остаётся превью до реализации договоров и AI-оценки условий. |

Частично будущие возможности: совет не назначает министров; охрана не вводит патрули.
Наблюдение, календарь, учёт, передача опыта и систематизация предлагают только локальные ограниченные модификаторы исследований. Сейчас эти эффекты не реализованы.
Новые ресурсы, профессии, рабочие места и API не добавлялись. Их необходимость описана в future-полях карточек.
После освоения каменного века доступ к остальным исследованиям сохраняется. Продолжение исторических эпох — U38; конкретный новый век в прототипе не выдумывается.
