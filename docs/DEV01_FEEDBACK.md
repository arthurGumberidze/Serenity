## Принятые уточнения

- Общая скорость совместной работы: 1× + 0,6× за каждого дополнительного реально работающего на месте.
- Соседи самостоятельно исполняют обычные работы без Ollama; Ollama — необязательный редкий советник.
- Esc закрывает верхнее окно; без окон открывает паузу. Игрок выбирает три исследования: они выполняются последовательно автоматически.
- Сохранить понравившиеся озеро, снежную гору и сакуру. Рыб добавить в реку, не в озёра.
- UMA разнообразие допустимо только без существенной потери производительности.

## Проверка

Связанные исправления компилировать/проверять пакетами через Tools/UnityRunner.ps1, не запускать Editor
для каждого пункта. Релевантные тесты обязательны для правил/сохранений; итоговый Windows Player
должен показать пользовательские сценарии и визуальные изменения. Не запускать полный 8-часовой прогон.
Отдельно записывать непокрытое, не объявлять весь перечень DONE по одному автоматическому smoke.
