## Разделение счётчиков образца

Runtime vegetation audit: 234 записи класса InteractiveTree, 428 DecorativeTreeOrShrub,
473 GroundCover. Отдельно проверены 4 canonical ягодных/грибных источника (лимит 80)
и 0 каменных источников (лимит 24) в сохранении routes11.
Физические proxies ограничены 156 деревьями в sample и 650 глобально; измеренные значения
приведены в validation/SR02. Количество source-записей не равно количеству активных коллайдеров.

В том же save есть 462 chop_wood source-записи: 220 соответствуют InteractiveTree,
241 — DecorativeTreeOrShrub, 1 — отдельному canonical population source.
Это существенное уточнение терминов: часть визуально декоративных деревьев существующей системы
тоже хранит конечный запас древесины. Число 234 не является числом всех потенциально рубимых деревьев.
Запасы не удалялись ради подгонки счётчика; JSON с деталями — Artifacts/SR02/sample-resource-budget.json.

04.11.2026 пользователь явно согласовал исключение: **462 рубимых дерева сохраняются вместе
с запасом древесины**, несмотря на исходный лимит 250 (D-254). Лимиты активных proxies 156/650
сохраняются. Это локальное разрешение для SR02, не автоматический бюджет будущей карты 2 км.
