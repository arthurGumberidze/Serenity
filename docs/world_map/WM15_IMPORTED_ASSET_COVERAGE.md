# WM15 — что уже есть для замены временных моделей

Аудит локального `Assets` от 26.10.2026. Главный вывод: **большую часть прежнего списка не нужно скачивать заново**. Модели уже импортированы либо лежат во вложенных пакетах. Основная оставшаяся работа — выбор моделей, подключение к ресурсам/постройкам, масштаб, материалы и анимация.

Это анализ наличия и пригодности кандидатов, не выполненная замена. Unity, игру, компиляцию, тесты и пересборку в этой задаче не запускали. Импортированные файлы не изменяли. Визуальная приёмка всех префабов в игре ещё нужна.

## Что действительно искать дополнительно

1. **Анимации человеческой работы под Humanoid:** рыбалка (заброс, ожидание, подсечка, вытягивание), добыча киркой, рубка с нормальным замахом/контактом, перенос мешка/корзины/бревна. Требуются клипы под используемых жителей, а не ещё один топор. В проекте есть `TownChop`, `TownCarry`, `TownWork` и `Armature|Carry/Work`, но их импорт настроен как **Generic**, поэтому это кандидаты для переноса, а не готовая замена на скелете Polytope/правителя.
2. **Анимированная пресноводная рыба**, если нужен готовый цикл плавания без самостоятельного rig/анимации. Для лежащего улова модель уже скачана.
3. **Небольшой комплект отдельных сырьевых предметов:** глина, растительное волокно, сырые/выделанные шкуры, узнаваемые куски железной/медной руды и кремня. Это необязательная покупка для первого прохода: мешки/корзины/камни уже закрывают отображение запасов, но не всегда позволяют узнать ресурс по силуэту. Отдельный зерновой набор сейчас не приоритет: зерна нет среди 26 записей текущего `ResourceCatalog.asset`.
4. **Специализированные эффекты рубки/добычи/попадания стрелы для URP**, если требуется заменить именно авторские частицы. All Nature VFX таких ударов по списку префабов не содержит.
5. **Опционально:** отдельная сушилка мяса и каменный рабочий стол, если не устраивает сборка из уже готовых предметов.

Не требуется повторно искать: обычные валуны, брёвна, кучи камня, мешки, корзины, мясо, пирсы, дубильные рамы, грядки, кормушки, заборы, общие деревья/цветы. Сначала использовать имеющееся.

## Важные уточнения по совместимости и содержимому

- **Лук:** `Assets/RTSToonBuildings/Animations/Animation_AttackArcher.fbx` уже содержит `AttackArcher`, кадры 0–35, Humanoid (`animationType: 3`). Перед поиском новых стрелковых анимаций надо проверить этот клип. `PT_Bow_*_anim` у Polytope — анимации оружия, а не всего тела человека.
- **Глина:** `HTClay.prefab` внутри Classic City Builder Kit существует, но проверка содержимого показала `SpriteRenderer`. Это 2D-ресурс, а не искомая 3D-куча.
- **Шкуры:** файлы `Medieval_Assassin_Girl/.../leather*.fbx` — части одежды персонажа. Их нельзя считать готовыми шкурами на земле.
- **Рыба:** `FX_Fish_*` в Tropical Jungle не содержит назначенного меша рыбы; материал ссылается на `Fish_01.png`. Для декоративного косяка допустим, для полноценной модели улова — нет.
- **Камни Polytope:** геометрия и основная текстура доступны, но `PT_Rocks_mat` использует собственный `PT_Rock_Shader`; часть дополнительных текстурных GUID не найдена в индексе Assets. Не обещать готовность без настройки. В исходном локальном пакете есть `PT_Nature_Free_URP_17.unitypackage`.
- **RTS/Toon Farm/Synty:** у просмотренных основных материалов есть локальные атласы и ссылка на используемый URP-шейдер. Это проверка файлов и ссылок, не доказательство корректного рендера каждого материала. Пустой путь GUID в отчёте может обозначать шейдер из PackageCache или встроенный ресурс, а не пропажу.
- **Medieval Action – FX Pack 2.0:** импортированы WAV-файлы. Это звуки, не щепки/кровь/ударные частицы.
- **AQUAS:** архив есть; в `Game/Art/WM15Late/Imported/Aquas` ранее выборочно перенесены текстуры волн. Полный водный рендерер не импортирован/не портирован этим аудитом. Не требуется ещё одна покупка AQUAS.
- **Снег:** наличие зимних моделей не устраняет плохую покраску земли автоматически. В первую очередь нужны согласованные слои террейна, переходы, масштаб и размещение; подмена всех камней белыми моделями повторит прежнюю проблему.

## Как проверялось

Полный список путей построен через `rg --files -uu Assets`, включая игнорируемые файлы. Сопоставлены `.meta` GUID, имена/тип содержимого префабов, материалы и их ссылки, метаданные FBX-клипов. Прочитаны каталоги локальных `.unitypackage`/ZIP и вложенных Unity-пакетов; несколько предметов дополнительно проверены по сохранённым внутри пакета миниатюрам. Это не визуальный просмотр каждой из тысяч моделей.

Учтены прежние выборочные импорты из `Artifacts/WM15LateFeedback/admitted-assets.json`: 17 файлов Arctic, 36 Stylized, 6 Ground, 3 Aquas физически существуют. Их новые GUID не совпадают с исходными, поэтому нулевое совпадение GUID архива само по себе не доказывает отсутствие выбранных копий.

Подробные машиночитаемые результаты: `Artifacts/WM15AssetCoverage/`. Компактные проверяемые сводки и команды сохранены в `docs/validation/WM15AssetCoverage/`. Ни один архив не импортирован в Unity в ходе этого анализа.
