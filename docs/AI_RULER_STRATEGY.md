# Стратег ИИ для соседних правителей

## Что реализовано

Внешняя языковая модель — необязательный советник над существующим `AiStrategicScheduler`. Она не получает
право создавать ресурсы, перемещать персонажей, ставить здания, начинать исследование, объявлять войну или
менять отношения напрямую. Модель возвращает один ограниченный агрегированный план; обычный игровой ИИ
проверяет его и выполняет только допустимые команды через канонические игровые сервисы.

Это рассчитано и на поселение с 2000 жителей: в запрос уходят численность, суммарные запасы, исследования,
число поселений/отрядов, отношения и доступные типы зданий. Имена и индивидуальные стратегии жителей не
передаются. Ответ содержит доли пяти рабочих когорт, целевые запасы, размер армии, дипломатическую позицию,
приоритеты зданий и одну общую цель.

## Режимы в настройках

В главном меню откройте `Настройки → Стратег ИИ для соседних правителей`:

- `Только игровой ИИ` — никаких внешних запросов; полностью детерминированный режим.
- `Ollama локально` — запрос к `qwen3.5:4b`; при любой ошибке продолжает обычный игровой ИИ.
- `Облачный API → Ollama` — сначала LLM Gate, при отсутствии ключа, сети, тайм-ауте или неверном JSON
  автоматически пробует Ollama, затем оставляет обычный игровой ИИ.

Смена настройки применяется при следующем запуске игрового мира. Настройка хранится отдельно от сохранений.

## Частота запросов

Один централизованный координатор допускает не более одного незавершённого запроса на поселение:

1. один раз в 365 игровых суток;
2. после принятого торгового дара/предложения;
3. при войне или продовольственном кризисе с отдельным cooldown;
4. по явному разговору игрока через `RulerStrategyRuntime.RequestDialogue`;
5. запрос не начинается на паузе.

Годовой план действует до следующего игрового года. Принятый план, незавершённый запрос и последние 32
результата сохраняются внутри стратегического состояния фракции. После загрузки старый сетевой запрос
отбрасывается; сохранённый незавершённый запрос можно безопасно отправить заново.

## Локальная Ollama

По умолчанию используются:

- endpoint: `http://localhost:11434/api/chat`;
- модель: `qwen3.5:4b`;
- `think=false`, `stream=false`, JSON mode, context 2048;
- тайм-аут 60 секунд.

Переопределения для нового процесса игры:

```powershell
[Environment]::SetEnvironmentVariable("SERENITY_OLLAMA_URL","http://localhost:11434/api/chat","User")
[Environment]::SetEnvironmentVariable("SERENITY_OLLAMA_MODEL","qwen3.5:4b","User")
```

Проверенный локальный ответ на текущем ПК занял 37,8 секунды на CPU. Усиленный prompt сохранил точные
машинные идентификаторы и русский текст только в поле `summary`.

## Облачный режим разработки

По умолчанию используются:

- endpoint: `https://api.llm-gate.tech/v1/chat/completions`;
- модель: `gpt-6-luna`;
- OpenAI-compatible Chat Completions JSON object response;
- ключ только из переменной процесса `LLM_GATE_API_KEY`.

Игра не записывает ключ в репозиторий, настройки, сохранение или журнал решений. После изменения пользовательской
переменной окружения нужно запустить новый процесс игры. Endpoint и модель можно переопределить:

```powershell
[Environment]::SetEnvironmentVariable("SERENITY_LLM_GATE_URL","https://api.llm-gate.tech/v1/chat/completions","User")
[Environment]::SetEnvironmentVariable("SERENITY_CLOUD_MODEL","gpt-6-luna","User")
```

Для публичной сборки нельзя раздавать общий платный ключ внутри клиента. `SERENITY_LLM_GATE_URL` должен указывать
на ваш backend/proxy, который аутентифицирует игрока, ограничивает расходы и уже на сервере хранит ключ провайдера.
Клиентский JSON-контракт и fallback при этом не меняются.

Официальная спецификация OpenAI Chat Completions и JSON response format:
https://developers.openai.com/api/reference/resources/chat/subresources/completions/methods/create

## Валидация ответа

Ответ отклоняется целиком, если он не JSON, содержит неизвестную цель/дипломатическую позицию, переводит или
выдумывает ID зданий, задаёт армию больше населения, выходит за ограниченные диапазоны или если проценты пяти
когорт не дают ровно 100. Отклонённый ответ никогда частично не применяется. Сетевой текст ошибки ограничен и
не содержит тело ответа или ключ. Каноническое состояние мира остаётся в детерминированных сервисах.
