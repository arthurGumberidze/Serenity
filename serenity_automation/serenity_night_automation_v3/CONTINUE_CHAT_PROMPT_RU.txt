КОНЦЕПЦИЯ
Serenity — одиночная real-time strategy / survival / city builder / dynasty simulator. Игрок — монарх. Игра начинается в Stone Age и в будущем развивается через последующие эпохи. Текущий MVP — Stone Age.

ТЕХНОЛОГИИ
Unity 6.x, C#, URP, DOTS/Entities, Jobs, Burst, Addressables, AI Navigation, Cinemachine, ScriptableObject, Unity Test Framework, PostgreSQL/Npgsql как durable persistence/history only. PostgreSQL НЕ realtime engine; активная симуляция живёт в RAM.

КЛЮЧЕВАЯ АРХИТЕКТУРА
- Character Domain != Character GameObject != DOTS Entity representation.
- StableEntityId persistent across save/load and Tier1↔Tier2↔Tier3.
- Tier1 = important/near-camera NPC with GameObject.
- Tier2 = ECS/DOTS active-city NPC.
- Tier3 = remote/lightweight simulation.
- No MonoBehaviour.Update per NPC AI.
- Resource quantities have exactly one canonical owner.
- Presentation never owns gameplay truth.
- Save/Load must not reroll deterministic state.
- Same seed + same state + same elapsed time preserves deterministic contracts.
- Never do two roadmap tasks at once.

TIME
1 game day at x1 = 24 real minutes.
Speeds x1/x2/x3/x5/x10 + pause.
Calendar time and biological time are separate. Biological aging uses accelerated biological ticks, not DateTime.
