==================================================
1. ЦЕЛЬ
==================================================

Доказать, что Serenity уже является цельной игрой Stone Age MVP, а не набором раздельных systems.

Новая игра:
start
→ resources
→ buildings
→ food
→ research
→ dynasty/health/weather
→ military
→ local/global
→ AI opponent
→ battle
→ capture/defeat AI state

без ручной правки XML/database/domain state.

==================================================
2. НИКАКОГО НОВОГО SCOPE
==================================================

U31 исправляет integration bugs.
Не добавляет:
- Wealth/Influence;
- ministries;
- taxes;
- diplomacy;
- espionage;
- later eras.

==================================================
3. NEW GAME BOOTSTRAP
==================================================

Проверь canonical new-game flow:
- seed/world;
- player settlement;
- AI settlement;
- exactly 10 starting player Characters with a valid monarch/dynasty;
- viable independent AI ruler/dynasty/population;
- resources;
- research starting knowledge;
- global map locations.

No hidden test-only final state.
Same seed/config produces the documented stable logical bootstrap hash. Starting a new game after a prior session does not duplicate roots/subscriptions.

==================================================
4. PLAYER UI ONLY FLOW
==================================================

Основной player-facing path должен быть доступен через U27 UI/normal controls.
Debug UI не требуется.

The E2E must drive the critical path through actual U27/U30A UI commands where PlayMode/UI automation can do so: New Game, time, selection/work, building, research, Save/Load, Local/Global, travel and battle entry. Direct service calls are allowed for lower-level setup/assertion only and cannot be the sole evidence that a player-facing action is reachable.

Test harness может вызывать те же canonical commands/services, но не мутировать финальное state напрямую.

==================================================
5. ECONOMY/SURVIVAL
==================================================

Player settlement:
- gather/store;
- build;
- produce food/material;
- survive seasons;
- no resource duplication;
- health conditions don't deadlock basic progression.

==================================================
6. RESEARCH
==================================================

Stone Age tree progresses.
Required unlocks become available.
No impossible deadlock.

==================================================
7. DYNASTY
==================================================

Ruler/heir state remains valid.
At least save/load around dynasty/family state.
Succession need not be forced in every E2E, but system must remain valid.

==================================================
8. MILITARY
==================================================

Create military unit/captain from canonical Characters.
Move on global map.
No duplicate roster.

==================================================
9. AI OPPONENT
==================================================

U26 AI actually develops independently and can launch action.
E2E must include real AI state, not static dummy only.
AI must construct at least one useful building/site through canonical resource/unlock rules during the campaign.

==================================================
10. BATTLE
==================================================

At least one canonical U23 battle must exercise both representations during the campaign:
- Abstract advancement off-camera;
- transition to Physical without reset;
- RTS player command/attack in Physical;
injuries/deaths persist;
captain/ruler integrations remain valid.

==================================================
11. CAPTURE / VICTORY CONDITION
==================================================

Use U24/U26 canonical defeat/capture rule.
No direct set `AI.Defeated=true` in test.

End state:
AI state genuinely defeated/captured according to documented MVP rule.
Victory is recorded exactly once and the same campaign continues in sandbox mode afterward; time, production and Save/Load remain operational.

==================================================
12. LOCAL↔GLOBAL
==================================================

Transition at least multiple times during E2E.
No regenerated Character/Building/Army.

==================================================
13. RTS↔TPS
==================================================

Required integrated combat check:
- enter TPS with the same eligible monarch/heir/captain during a Physical U20/U23 battle;
- aim and perform at least one canonical attack through shared U20 rules;
- companions continue AI orders;
- return RTS;
- Character, unit, battle, health, target and cooldown state remain preserved.

TPS does not have to deliver the winning blow, but movement-only smoke is insufficient.

==================================================
13A. DISCOVERY AND SUPPLY
==================================================

- The player must discover/contact the initially unknown AI state through the canonical U30A knowledge boundary before using full enemy details.
- Player and AI armies consume/preserve canonical minimal Stone Age supply during travel/battle.
- Physical↔Abstract and Save/Load cannot refill, duplicate or lose supply.

==================================================
14. EVENTS
==================================================

U28 event system active.
No event duplication.
Player-choice event handling does not block campaign incorrectly.

==================================================
15. SAVE/LOAD CHECKPOINTS
==================================================

E2E must save/reload representative points:
- early settlement;
- after research progression;
- global travel/battle;
- after major capture if practical.

Continue same campaign.
